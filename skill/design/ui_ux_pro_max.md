# [SKILL] UI/UX Pro Max v2.5.0
**Objetivo:** Proporcionar inteligencia de diseño avanzada para la creación de interfaces profesionales en múltiples plataformas y frameworks.

## Descripción
Esta habilidad utiliza un motor de razonamiento con 161 reglas específicas de la industria para generar sistemas de diseño completos (patrones, estilos, colores, tipografía y efectos).

## Capacidades
- **Estilos:** 67 estilos UI (Glassmorphism, Minimalism, Neumorphism, etc.).
- **Paletas:** 161 paletas de colores curadas por industria.
- **Tipografía:** 57 emparejamientos de fuentes de Google Fonts.
- **Componentes:** Recomendaciones de 25 tipos de gráficos y 99 guías de UX.
- **Stacks Soportados:** React, Next.js, Astro, Tailwind CSS, shadcn/ui, y más.

## Protocolo de Uso
Cuando el usuario solicite trabajo de UI/UX:
1. **Generar Sistema de Diseño**: Analizar los requisitos del producto y generar el "Recommended Design System".
2. **Aplicar Estética Premium**: Utilizar paletas armoniosas, tipografía moderna y micro-animaciones.
3. **Validación**: Verificar contra la lista de anti-patrones y accesibilidad (WCAG AA).
4. **Persistencia**: Si se solicita, guardar el sistema de diseño en `design-system/MASTER.md`.
